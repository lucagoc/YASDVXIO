# YASDVXFW

An opinion-oriented fork of CrazyRedMachine SDVX Controller Firmware.

## Features

### I/O
- 9 buttons (7 buttons + service + test)
- 7 button lights
- Compatible with ATMega32U.
- Designed for chinese encoders.

## Building

This project rely on [PlatformIO](https://platformio.org/).

- Clone the projet.
- Run 

## Pinout
Arduino Leonardo uses 5V logic, so 5V LEDs can be connected directly.
